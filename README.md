# Cognitive IQ Lab v6

Cognitive IQ Lab 是一個原創、多構面的 IQ-style 認知測驗網站。

## v6 功能

- 正式測評風格首頁
- 30 題、6 個認知構面
- 7 題 Raven-like 原創 3×3 圖形矩陣題
- 點選答案後自動前往下一題
- 可回上一題修改答案
- 快速跳題
- 每題切換動畫
- 工作記憶與處理速度題型
- 題目旁會明確標示「限時」或「不限時」
- 只有題庫中明確設定 `limit` 的題目才會倒數
- 限時題最後 5 秒會加強視覺提醒
- 限時題逾時後會永久鎖定：不能再選答案，選項會消失
- 工作記憶題目前採「記憶內容顯示 3 秒，作答不限時」
- 顯示整份測驗的總累積時間
- 不限時題不因作答較慢而被扣速度分；只有限時題才把速度納入該構面
- 高級結果圖表：
  - 能力分布雷達圖
  - 答題結構環形圖
  - 構面表現比較長條圖

## 執行方式

直接開啟 `index.html` 即可使用。網站為純前端，不需要建置步驟或後端服務。

## 檔案結構

- `index.html` — 首頁、測驗與結果頁結構
- `styles.css` — UI、RWD、題目切換動畫與圖表樣式
- `questions.js` — 30 題原創題庫；需要限時的題目可設定 `limit`
- `app.js` — 基礎答題流程、返回上一題、結果計算與圖表繪製
- `timeout-lock.js` — 限時／不限時模式、總測驗時間、逾時鎖定與計時相關計分邏輯

## 版本沿革

- v2：30 題、多構面 IQ-style 測驗
- v3：明亮介面、上一題、自動下一題
- v4：更清晰、大字版
- v5：正式版 UI + 題目轉場動畫
- v6：正式首頁 + Raven-like 矩陣題 + 高級圖表 + 分級計時模式 + 總測驗時間

## 重要限制

本網站不是 WAIS、Stanford–Binet 或 Raven’s Progressive Matrices 的正式線上版本，也未使用其正式題目、常模或專有計分演算法。

目前顯示的 IQ-style Cognitive Index 僅供自我訓練與娛樂參考，不應用於醫療、教育鑑定、升學或就業決策。
